## Descripción
El siguiente proyecto es una aplicación movil desarrollada con Flutter/Dart, esta aplicación es una banca virtual la cual nos permite ver un resumen de cuentas, realizar transferencias, ver historial de trasnferencias, agregar cuenta destino y personalizar la aplicación según cada usuario.

## Objetivos
- Proveer de un aplicación de banca virtual con interfaz amigable.
- Facilitar Transacciones y tranferencias bancarias.
- Obtener resumen de cada transaccion de cuentas.

## Desarrollo
El app se desarrollo utilizando las mejores tecnologías y mas recientes para poder obtener una mejor escalabilidad dividiendo responsabilidades dentro de cada una de las capas lo cual incluso facilita cualquier tipo de mantenimiento. Por este motivo utilizamos una combinación de Riverprod + Notifier + Freezed dentro de una Clean Arquitecture. Con este desarrollo al utilizar Freezed podemos manejar estados especializados.

En resumen las tencologías utilizadas dentro del desarrollo de la aplicación nos da un mejor mantenimiento, rendimiento, escalabilidad, reducción de estado de errores y una separación bastante clara entre UI el negocio y los datos.

La aplicación permite cambiar el idioma entre español e inglés desde un selector visible para el usuario. Este selector está disponible en la pantalla de inicio de sesión y también dentro de configuración, por lo que el idioma puede modificarse antes o después de entrar a la app.
Cuando el usuario selecciona un idioma, la interfaz se actualiza usando los textos correspondientes definidos para cada idioma. Por ejemplo, etiquetas como correo, contraseña, login e idioma cambian automáticamente según la opción elegida. Además, la selección queda guardada, así que al cerrar y volver a abrir la aplicación se mantiene el idioma preferido del usuario.

## Estra Firebase
El login de la aplicación está conectado con Firebase Authentication para validar el acceso del usuario usando correo y contraseña. Desde la pantalla de inicio, el usuario ingresa sus credenciales y la app envía esa información a la capa de autenticación. Mientras se procesa la solicitud, la interfaz muestra un estado de carga y, si ocurre algún error, se presenta un mensaje claro en pantalla.
Cuando Firebase confirma que el usuario es válido, la aplicación guarda ese estado como sesión autenticada y redirige automáticamente al dashboard. También se escucha el estado de sesión, por lo que si el usuario ya había iniciado sesión anteriormente, la app puede reconocerlo y evitar que tenga que volver a ingresar sus datos. Al cerrar sesión, Firebase elimina la sesión activa y la aplicación regresa al login.

Dentro de cada feature se mantiene la misma intención arquitectónica:

- `data`: implementa fuentes remotas, modelos y repositorios concretos.
- `domain`: contiene entidades, contratos y casos de uso sin depender de Flutter.
- `presentation`: agrupa vistas, widgets y estados manejados con Riverpod/Notifier.
- `core`: centraliza dependencias compartidas como red, rutas, ambiente, Firebase, assets e idioma.
